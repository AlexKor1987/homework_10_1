# Проект Домашняя работа 10.2, 11.1 и 11.2

## Описание:
В данной программе реализовано несколько домашних работ: 10.2, 11.1 и 11.2, добавлены соответствующие программные модули.

Проект Домашняя работа 10.2 - это программа, написанная на языке Python, которая возвращает новый список словарей, содержащий только те словари,
у которых ключ state соответствует указанному значению. Также эта программа принимает список словарей и необязательный параметр, задающий порядок 
сортировки(по умолчанию — убывание) и возвращать новый список, отсортированный по дате. Также в этой программе реализовано тестирование всех 
функций модулей.

Проект Домашняя работа 11.1 - это программа, написанная на языке Python, в которой созданы инструменты для эффективной работы с большими объемами 
данных транзакций, используя возможности Python для обработки данных через генераторы. Эти генераторы должны позволять финансовым аналитикам быстро 
и удобно находить нужную информацию о транзакциях и проводить анализ данных. Создан модуль generators, который будет содержать функции для работы 
с массивами транзакций.

Проект Домашняя работа 11.2 - это программа, написанная на языке Python, в ней разработан декоратор "log", который будет автоматически регистрировать 
детали выполнения функций, такие как время вызова, имя функции, передаваемые аргументы, результат выполнения и информация об ошибках. Это позволит 
обеспечить более глубокий контроль и анализ поведения программы в процессе ее выполнения.

## Использование:

1. Откройте прорграмму в PyCharm.
2. В модуле "processing" напиcана функция "filter_by_state", которая принимает список словарей и 
опционально значение для ключа "state" (по умолчанию 'EXECUTED'). Функция возвращает новый список 
словарей, содержащий только те словари, у которых ключ "state" соответствует указанному значению.
3. В том же модуле "processing" написана функция "sort_by_date", которая принимает список словарей 
и необязательный параметр, задающий порядок сортировки (по умолчанию — убывание). Функция возвращает
новый список, отсортированный по дате (date).
4. В модулях "conftest" и "test_main" реализовано тестирование кода.
5. В модуле "generators" напиcана функция "filter_by_currency", созданы генераторы "transaction_descriptions"
и "card_number_generator"
6. Функция "filter_by_currency" в модуле "generators" принимает на вход список словарей, представляющих 
транзакции. Эта функция возвращает итератор, который поочередно выдает транзакции, где валюта операции 
соответствует заданной (например, USD).
7. Генератор "transaction_descriptions" в модуле "generators" принимает список словарей с транзакциями и 
возвращает описание каждой операции по очереди.
8. Генератор "card_number_generator" в модуле "generators" выдает номера банковских карт в формате 
"XXXX XXXX XXXX XXXX", где "X" — цифра номера карты. Генератор генерирует номера карт в заданном диапазоне 
от "0000 0000 0000 0001" до "9999 9999 9999 9999". Генератор принимает начальное и конечное значения для 
генерации диапазона номеров.
9. В модулях "conftest" и "test_generator" реализовано тестирование кода.
10. В модуле "decorators" реализован декоратор "log" и "printing_start_finish_time". Декоратор "log" автоматически
регистрирует детали выполнения функций, имя функции, передаваемые аргументы, результат выполнения и информация об 
ошибках. Декоратор "printing_start_finish_time" предназначен для вывода времени начала и времени окончания работы 
программы, а также её длительности.
11. В модуле "test_decorators" реализованы тесты, проверяющие функциональность декоратора.
